## Featured projects

### [P2PMessenger](https://github.com/sergdeathless/P2PMessenger)
A native iOS peer-to-peer messenger built with Swift. Supports private and group chats, local message history, unread counters, onboarding, local notifications, and nearby-device communication without an external server.

`Swift` `SwiftUI` `MultipeerConnectivity` `XCTest` `GitHub Actions`

### [backendS7MIPT](https://github.com/sergdeathless/backendS7MIPT)
A delivery-forecasting platform with a FastAPI backend and Dash interface. It combines JWT-protected APIs, PostgreSQL, Docker Compose, and a heatmap for exploring delivery lead times across regions and parts.

`Python` `FastAPI` `PostgreSQL` `Docker` `JWT` `Dash`

### [swiftCalc](https://github.com/sergdeathless/swiftCalc)
A focused Swift calculator project and a foundation for exploring native Apple-platform development.

`Swift` `UIKit`
